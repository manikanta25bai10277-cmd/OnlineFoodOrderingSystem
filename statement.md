## Project Title

Online Food Ordering System

## Problem Statement

The Online Food Ordering System is designed to simulate the process of
ordering food from a restaurant through a Java-based application.

The system provides separate access for customers and administrators.
Customers can log in, browse the restaurant menu, select food items,
manage their cart, place orders, choose a payment method, and track
delivery updates.

Administrators can log in to view restaurant information, manage the
restaurant menu, and add new food items.

The application also validates user input, handles exceptions, processes
payments, and stores completed order information using file handling.

## Scope of the Project

The project covers the basic workflow of an online food ordering
application.

The scope includes:

- Customer and admin authentication
- Restaurant and food menu management
- Shopping cart management
- Food ordering
- Payment method selection
- Order status tracking
- Previous order viewing
- File-based order storage
- Graphical User Interface using Java Swing
- Command-Line Interface

The project is implemented as a local Java application and does not
include real online payment processing or a cloud-based database.

## Target Users

### Customers

Customers can use the system to:

- Log in to the application
- Browse food items
- Add food to the cart
- Place orders
- Select payment methods
- View previous orders
- Track delivery updates
- Log out

### Administrators

Administrators can use the system to:

- Log in
- View restaurant details
- View the food menu
- Add new food items
- Refresh the menu
- Log out
